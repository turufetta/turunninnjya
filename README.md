# 🥷 つるふぇったの手裏剣修行  
**Tsurufetta's Shuriken Training**

忍者になって手裏剣を投げるアクションゲームです。

## 遊び方

1. スタート画面で段位を選ぶ（最初は**初段のみ**）
2. 照準を合わせて「手裏剣！」で投げる
3. 的の**中央**に当てるとアイテムGET＆クリアカウント
4. 氷爆弾は手裏剣で撃ち落とす（失敗すると毒ダメージ）
5. 段位クリアで次の段が解放

## 段位解放

| 段位 | クリア条件 | 解放条件 |
|------|------------|----------|
| 初段 | 中央ヒット 5回 | 最初から |
| 中段 | 中央ヒット 8回 | **初段クリア後** |
| 上段 | 中央ヒット 12回 | **中段クリア後** |

## アイテム

- 青 👑 水の王冠 … 二刀流
- 緑 🍵 お茶 … 「ありがと！」
- 赤 🧊 氷爆弾 … 敵攻撃を消す
- 黄 🌸 花 … 手裏剣増加＋ボイス

## GAME OVER

氷爆弾被弾：初段10回 / 中段8回 / 上段6回 でGAME OVER

## 上段クリア

湯上がりつるんロボ登場 ＋ 伝説の忍者ボイス ＋ Xでシェア可能
